로타리 패커 생산 실적

금일·전일 생산량, 가동시간, 시간당 포대 생산량과 1~8번 스파우트별 실적을 확인합니다.

입력값 기반 · SCADA 실시간 연동 아님
중요: 실제 SCADA 태그 연결 전에는 수치를 직접 입력해야 합니다. 시간대별 실적과 스파우트별 실적은 현재 예시값을 만들지 않으며, 비어 있는 항목은 미입력으로 표시됩니다.

로타리 패커 사진 첨부 · 자동 판독

사진 여러 장 한 번에 선택

SCADA의 로타리 패커 화면 사진을 선택하면 OCR로 문자를 읽고, 인식된 금일·전일 생산량과 가동시간을 아래 입력칸에 채워 넣습니다. 숫자를 자동 확정하지 않으므로 반영된 값을 확인한 뒤 사용하세요. 처음 실행 시 OCR 언어 파일 다운로드로 시간이 더 걸릴 수 있습니다.

일일 생산 및 가동시간
포대 기준

    

     

     

     

     

     

     

    

    

    
금일 생산량과 가동시간을 입력하면 시간당 평균 포대 생산량을 계산합니다.

   

   
스파우트별 생산량
1~8번

    
각 스파우트의 실제 카운터 값을 입력하세요. 전체 합계와 금일 총생산량을 비교합니다. 실제 태그가 연결되면 수동 입력 대신 자동 수신하도록 확장할 수 있습니다.

    

    

    
스파우트별 값이 아직 입력되지 않았습니다.

   

  

  
시간대별 생산 실적
시간별 포대 수 입력

   
금일·전일 시간당 평균 생산량은 각 일자의 총 생산량 ÷ 해당 일자의 실제 생산가동시간으로 자동 계산됩니다. 아래 00~24시 표는 시간대별 실제 포대 수를 입력하는 별도 기록이며, 평균값을 실제 시간대별 실적으로 오인하지 않도록 구분합니다.

   
금일·전일 생산량과 가동시간을 입력하면 시간당 평균 포대 수가 여기에 표시됩니다.

   
시간대생산량 (포)가동 여부시간당 생산량 (포/가동시간)
입력 합계—시간대별 실적 미입력

   
 

   
현재 화면은 초기 홈페이지를 유지하면서 로타리 패커 항목만 추가한 시제품입니다. SCADA에 시간별/스파우트별 카운터가 없다면 해당 상세값은 자동으로 만들어낼 수 없으며, 현장 태그나 시간대별 계량 기록이 필요합니다.

사일로별 마감 재고 · 긴급 발주 확인
현재 용량과 원료 지정 반영

   
마감 때 확인한 잔량(톤)을 입력하세요. 재고가 0톤이면 긴급 발주, 다음날 계획 소요량보다 적으면 발주 필요로 표시합니다. 6번 사일로는 미분/석탄재를 실제 생산 상황에 맞게 선택합니다.

   

   
사일로원료용량(T)마감 잔량(T)상태

   

   
마감 잔량을 입력하고 확인을 누르면 발주 필요 원료를 표시합니다.

  

  

   
다음 날 2·3호기 생산 가능량 예측
로타리 패커 전용

   
금일 패커 생산량과 가동시간으로 시간당 생산속도를 계산합니다. 다음 날 계획 가동시간과 사일로 재고를 반영해 예상 생산 가능 포대를 계산합니다.

   

    

    

    

   

   

   
먼저 로타리 패커 탭에 금일 생산량·가동시간을 입력하고, 사일로 마감 잔량을 저장하세요.

  

  

   
평일 목표 생산량별 원료 소요량
현재 입력된 임시 배합 기준

   
아래 계산은 사용자가 알려준 3.3톤 배합을 임시 기준으로 사용합니다. 제품별 실제 배합은 내일 제공할 사진을 반영해야 합니다. 현재 입력된 원료 합계는 3,299kg이며, 보고된 총량 3,300kg과 1kg 차이가 있어 차이를 임의로 보정하지 않고 3,300kg 기준으로 비율 환산합니다.

예측 시 주의사항
다음 날 생산량은 패커 속도와 원료 재고 중 더 작은 조건에 제한됩니다. 현재 배합은 제품별 레시피가 아닌 임시 참고값이며, 25kg 제품 및 타일 떠붙임의 실제 배합이 확인되면 제품별로 다시 계산해야 합니다. 평일 목표는 생산 계획 입력값이며 자동으로 평일 달력을 판정하지 않습니다.

단위 확인 필수: 가스는 계량기 보정 조건과 단위, 모래는 계량 방식(로드셀·배치 중량·재고 차분)을 확인하기 전까지 수치를 비교할 수 없습니다.

시작/종료 누적값

운영 시 주의점
  • 가스 종료 누적값이 시작값보다 작으면 계량기 초기화/교체 여부를 확인해야 합니다.
  • 모래 사용량은 단순 재고 차분 외에 입고·반품·이송량을 반영해야 정확합니다.
  • 톤당 사용량 비교는 같은 제품군, 같은 기간, 동일한 생산량 기준으로 비교해야 합니다.
  • 실시간 경보보다 일별 집계는 시간대·교대조 기준을 명확히 정해야 합니다.
